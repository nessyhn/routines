# 🛡️ Güvenlik Politikası (Security Policy)

## Desteklenen Sürümler
Şu an aktif olarak en son ana sürüm desteklenmektedir.

## Güvenlik Açığı Bildirme
Bir güvenlik açığı keşfettiyseniz, lütfen bunu herkese açık bir Issue açarak **paylaşmayın**. Bunun yerine proje yöneticileri ile iletişime geçin veya GitHub Private Vulnerability Reporting özelliğini kullanın.
